# 猫猫电视机结构

GTIT 2.0.14 将原猫猫售货机的结构改为宽 5、高 4、深 2（高×宽×深为 4×5×2）。共 40 格，控制器位于正面底边中央；其余 39 格均沿用既有外壳／ME 仓检查链，包含屏底六格。ME 仓数量规则仍沿用原机。

结构定义的两层均从上到下、从左到右排列：

```text
正面        后层
ccccc       ccccc
ccccc       ccccc
ccccc       ccccc
cc~cc       ccccc
```

创造建造、生存建造和成型检查共用控制器偏移 `(2,3,0)`。不注册新方块、控制器 ID 或存档格式，也不自动移动世界方块。原 2×2×1 结构需按新尺寸重新搭建；原控制器及其中保存的库存、队列等仍沿用原有数据。

正面内侧 3×2 格沿用 GT5U `RenderOverlay`，从上到下、每行从左到右拼接六张 32×32 贴图，组成 96×64 固定画面。屏幕材质与具体玩家的交易、签到、邮件、钱包等数据无关；关闭动画时显示同主题静帧。旧贴图字段仍保留，避免破坏已有调用。

`tools/artgen_catalog/neko_tv/bake.py` 从仓内 SVG 和原猫猫币纹理生成静态图与 120 帧条带；每帧 2 ticks，共 12 秒。两枚币的绘制框均为 48×48 像素，原四帧实际币面最窄为 37.5 像素，大于一个 32 像素方块面。币持续向下穿屏，仅在屏外回绕。

结构测试核对真实编译后的外壳检查链、唯一控制器、六块屏幕坐标与各朝向映射；素材脚本验证六片逐帧重拼。这些检查不能替代实际游戏中的成型、仓室接入或屏幕渲染验收。
