# 猫猫全息投影仪（v1.8.73）

在猫猫贸易的 GTIT 分类中，用 **1 枚闪烁猫猫币**兑换。本文按 v1.8.73 源码说明；本轮未启动游戏客户端或服务器，实际性能与游戏交互由用户实测。

## 常用操作

| 要做什么 | 操作 |
| --- | --- |
| 选择机器 | 手持投影仪右键多方块控制器；空中右键可重新打开已有工作台。 |
| 看结构 | 切换「目标 / 现场 / 差分」；拖动旋转，滚轮缩放，选择全部层或单层。点击色块查看真实物品图标、目标及原因。 |
| 设置等级 | 点击「等级 / 信道设置」，选择具名等级，或输入原始正整数。 |
| 设置任意子信道 | 在信道面板填写 name 和 value，点「添加 / 更新」；已有信道也可修改或删除恢复继承。无需列在适配名单中。 |
| 补建空位 | 切「建造」，核对范围与材料，点「查看差分 →」，再点「确认并直接施工」。 |
| 外壳换仓室 | 切「替换」和「允许仓室」，点允许仓室的结构格，从候选或背包指定仓室，然后确认差分。 |
| 仓室换仓室 / 外壳 | 切「替换」，选旧仓室所在格并指定该格允许的目标；旧仓室单独封存回收。 |
| 拆整台机器 | 切「拆除」，默认全结构且包含仓室、框架与控制器；核对回收空间并确认。控制器最后拆。 |
| 只拆外围 | 拆除时打开「保留控制器 ✓」；也可改为当前层、选中格或同类部件范围。 |
| 开关世界提示 | 点击「世界投影」。默认关闭；开启后只显示简单线框。 |
| 机器不支持高级采集 | 使用「原版提示 / 原版构造」，走该机器自己的构造接口。 |

## 等级与子信道

主信号与子信道支持 **1–2,147,483,647** 的正整数。具名等级是便捷选项，不限制手动数值；当前未使用、未适配或从其它机器保存的子信道也可以编辑。未指定的子信道由 StructureLib 回退主信号，部分机器按是否存在该键决定行为。删除或选择继承会移除显式设置。

手填名称为 1–48 位小写字母、数字、下划线、点或连字符；一次最多保存 64 个子信道。main 表示主信号。设置会重新采集结构；数值如何影响层数、材料或等级由目标机器解释，填一个机器不读取的键不会产生效果。控制器朝向只读，旋转预览不会旋转机器。

已提供的具名选项包括 EBF/Coke 线圈、EBF 自动仓室、Extractor 管道与玻璃、EIC 玻璃与活塞、Mega Distillation Tower 高度、Coke Oven 壳体与长度；其它信道使用原始整数输入。

## 背包选材与替换

「从背包指定目标」展示玩家主背包 36 格。点击物品后点「指定目标」，或把物品拖到左侧预览格；只复制目标，不移动或消耗库存。服务端根据槽位读取实际物品，确认施工时才扣材料。「清除目标」恢复结构默认或信道目标。

建造只补空位，改变已有部件要用替换模式。可将高炉允许仓室位置的机械外壳换成输入、输出、能源等该位置接受的仓室；专用消声位置仍只能使用它接受的类型。手选仓室按结构声明的类型、黑名单及追加过滤检查，自动补仓室的“数量已够”不会阻挡手动选择。自动仓室选材仍遵守原版自动构造规则。

「只放外壳」只影响建造/替换；从背包指定合法仓室会自动开启允许仓室。拆除不受这个开关影响。线圈替换通过线圈信道统一指定。全结构、当前层、选中格和同类部件分别控制操作范围；同类部件要求能识别该家族，请在确认页核对实际格数。

旧 GT 仓室不会把内容自动搬到新仓室：旧设备、库存、流体与盖板等可持久化状态封存在回收物品中；新设备使用目标物品的状态。封存物品可按正常右键放置恢复，投影仪也可使用它作为目标。恢复时核对持久化数据，失败会还原现场并保留物品。封存物品即使在创造模式也会实际消耗一枚，避免复制其中的库存和流体。不要删除封存物品的 NBT。

## 直接施工与完整拆除

「查看差分 →」会重新扫描现场；等待回执后，确认页列出范围、差分格数、材料缺口、回收数量和保护原因。只有第二步「确认并直接施工」才改变世界。

不再播放逐格或下落动画，也没有每层一秒、层间等待或八 tick 预告。通常一次服务端批次完成全部可执行格；原生元素明确要求 STOP/ACCEPT_STOP 时遵从其下一 tick 规则，STOP 同格重试有上限。施工期间界面保留，完成以服务端真实回执为准。

完整拆除覆盖采集到的真实结构部件，包括合法 GT 仓室、普通/带盖板框架，以及准确声明的外壳、玻璃、线圈和其它普通方块。内部要求为空的位置不会被当作部件随意清空；未知接口、未支持的非 GT 设备和权限禁止位置会显示原因。

默认最后回收控制器并结束当前任务。如果外围仍有失败或未完成格，会保留控制器供重试；开启「保留控制器」也会保留锚点。拆除成功后工作台保留最终数量，重新右键新控制器开启下一任务。

暂停、继续和取消只作用于尚未完成的任务；取消保留已经成功改变的世界与材料消耗，不撤销整台机器。缺料、回收空间不足、现场被外部改变或放置被拒绝时会提示原因；调整后重新扫描并确认。普通块创造模式沿用不掉落规则，GT 设备创造模式也封存回收其已有状态。

## 预览与适用边界

预览用简单色块表示结构与状态，不调用真实方块或机器模型；相机变化才重算投影，裁掉背面与内部面。选中格旁显示实际与目标物品图标。世界提示是缓存的批量线框，可按层过滤，离开会话或关闭时释放缓存。

绿色表示满足/完成，蓝色待施工，红色缺料，金色保护，紫色不支持。预览不执行机器成型检查；放置成功不等于仓室配额、最低外壳数量等成型规则都满足。

高级采集以当前 GT 多方块提供的 StructureLib 构造定义为准，最多 4096 格；采集不完整时不会用残缺计划施工。封存只针对已实现完整持久化的 GT 机器/框架路径；不保证其它 Mod 设备或运行时网络引用能随设备迁移。原版构造回退使用机器原生行为，不提供高级差分事务与回收账。
