# 猫猫全息投影仪（v1.8.89 操作说明）

在猫猫贸易的 GTIT 分类中，用 **1 枚闪烁猫猫币**兑换。GTIT 任务线 ID38 检索投影仪后奖励 1 枚闪烁猫猫币，不消耗投影仪。本页介绍工作台、结构编辑、蓝图保存与放置的常用操作。

## 常用操作

| 要做什么 | 操作 |
| --- | --- |
| 打开工作台 | 手持投影仪 Shift+右键打开工作台。工作台左侧可切换「结构」和「蓝图」标签；Shift+右键不再是全局设置入口。 |
| 看结构 | 在「结构」标签切换「目标 / 现场 / 差分」，拖动旋转、滚轮缩放，选择全部层或单层。点结构淡框边缘可整选该结构。 |
| 选择结构格 | Ctrl+点击多选；按住 Shift 在预览中从一格拖到另一格，按立体区域选格；G 或「移动轴」切换 RGB 轴，拖动红 X、绿 Y、蓝 Z 轴移动所选蓝图格。 |
| 框选世界区域 | 手持投影仪 Shift+Alt+右键切换区域选择模式；模式开启时投影仪有附魔效果提示，世界中显示 GTUDK 线框。左键设第一点，右键设第二点；按住 Alt 时以玩家坐标设点。再次 Shift+Alt+右键退出；两点齐全时开始导入区域并识别其中的结构。 |
| 编辑导入区域 | 导入后点击预览中对应结构的淡色边框整选单个识别结构，再用「结构编辑 / 施工」控制；也可切回区域模式编辑整片区域。编辑时仍可使用多选、立体框选及 RGB 轴。 |
| 设置等级和子信道 | 打开「等级 / 信道设置」，选具名等级或填原始正整数；任意子信道可输入名称和值，再添加、更新或删除。 |
| 补齐或改造结构 | 选「补建」或「替换」和施工范围，再由确认页检查改动。生存模式只填空位，不替换现有方块；替换仅适用于完整的原结构位置。 |
| 保存或编辑蓝图 | 在「结构」页完成编辑后切到「蓝图」标签，执行「另存蓝图」或「更新蓝图」；保存默认选择全部可写 NBT 根条目，可在保存选项中取消单项。编辑已有蓝图时从蓝图页选择并进入结构编辑。 |
| 设提示或排除方块 | 打开「提示词」；提示可设为全局、选中方块或当前立体提示区。可将所选格排除出施工，也可恢复施工；提示会随蓝图保存并可悬停查看。 |
| 分享蓝图 | 在「蓝图」标签用「导出 / 导入」操作分享 JSON；文件位于服务端 config/gtit/hologram-blueprints/ 目录，名称格式为 &lt;名称&gt;.json，名称仅可用 a-z、A-Z、0-9、下划线和短横线且长度为 1–64 字符，单文件上限 8 MiB。跨服务器分享需手动搬运文件到另一服务器同目录；这里不提供在线公共平台。导入后在列表中选择并查看版本信息。 |
| 每次放置蓝图 | 手持投影仪 Alt+右键启动放置。每次都会先打开蓝图选择与材料确认界面；核对资源、材料后确认才进入世界预览。可在本次 NBT 确认中临时取消根条目或覆盖板，不会改动已保存的蓝图选项。预览中按 Alt+右键锁定位置，再按 Shift+右键重开工作台，点「确认执行」施工。材料不足时先显示缺口，可再次确认只施工已有材料对应的格。 |
| 查看兼容性和缺失方块 | 蓝图「版本信息」按红色缺失、橙色过时、青色超前显示 Mod 版本；选中缺失方块可查看方块 ID、来源 Mod 与蓝图版本。 |
| 使用 AE 缺料接口 | 库存和流体可使用已启用且有适配的 AE 资源来源；「AE 下单接口」是 provider hook，默认禁用，不包含内置下单或 crafting。 |

普通结构施工使用「材料与改动」核对需求与现场变化；蓝图放置每次都要先在材料确认页确认，再进入世界预览，最后在工作台确认施工。施工不播放逐格动画；所有入口沿用服务端安全预检。蓝图的内部库存、流体、储能和覆盖板规则见下方说明。

补建和替换各自处理不同位置。补建只填空位，匹配的现有方块保持原样；调整现有仓室朝向也须使用替换。生存模式所选范围有被遮挡位置时，不启动本次补建、不扣材料。创造模式可以覆盖普通占位方块，控制器、未适配设备、权限及 Forge 事件保护仍有效。

保存蓝图后，服务器确认成功才更新「蓝图」列表并自动定位新条目，以勾号标记当前项。重新打开列表也会定位当前项；超过四项用滚轮浏览。列表显示总数，底部明确显示保存结果或配置读取错误，悬停可查看完整原因。实体控制器可另存蓝图；已有蓝图可在编辑界面更新原项或另存新项；普通列表选择只记录选择，不启动世界投影，也不退出编辑。没有结构的蓝图编辑需先选择已有项。

替换须绑定真实控制器，开工前确认原结构已完整构建。只替换已识别的原结构方块或合法仓室，不在空位施工；手动添加的位置、结构声明的空气位置不能用于替换别的建筑。虚拟预设用于补建，需改已有结构时打开其真实控制器。执行中再次核对现场，变化后停止，已完成结果保留。

## 选位置与自由替换

工作台采用 600×340 基准尺寸，左侧是结构预览与结构/蓝图标签，右侧固定显示属性和蓝图列表；控制面板按钮横向按原宽度 60% 绘制，确认/取消/中性按钮分别用绿/红/青色提示。界面不随大屏放大，并按 Minecraft GUI 缩放后的可用区域收缩，宽高分别保留至少 10% / 15% 边距。普通点击用于检查位置，不会把施工范围悄悄改成单格。再次点击选中格、点击预览空白或右键可取消选中；主界面「取消格选择」同样可用。Esc 优先取消拖拽与弹窗，再取消格选择，最后退出工作台。Delete 和「恢复默认壳」明确把当前格设回结构默认壳体目标，并抑制预设重新填回；已造仓室要点击「应用替换」才实际回收和还原。无默认壳体的固定接口会说明原因，不猜造外壳。明确指定物品或添加位置后，自动转为单格；批量操作主动选择范围.

| 默认快捷键 | 作用 |
| --- | --- |
| Ctrl+X / C / V | 在结构规划中剪切、复制、粘贴目标和朝向；在蓝图编辑中剪切、复制、粘贴所选蓝图格。蓝图剪切只将源格标为排除，不改动世界。 |
| Ctrl+点击 | 将点击格加入或移出多选。 |
| Shift+拖动 | 从已有选择角点或当前格拖到第二点，选择两点之间的立体区域；可同时按 Ctrl 保留已有选择。 |
| G | 显示或隐藏移动轴；拖动 RGB 轴沿一个世界方向移动选中蓝图格。 |
| Delete | 恢复选中格的默认壳体目标。 |
| R | 按北→东→南→西→上→下轮询选中仓室的合法朝向。 |
| Ctrl+Z / Y | 撤回、重做最多 32 步目标规划；不回滚世界施工。 |
| 1 / 2 / 3 | 补建、替换、拆除模式。 |

连续快捷键最多排队 8 项，按服务端确认顺序执行；按世界坐标重新定位，关闭界面、切换会话或采集变化时取消待执行项。

局部剪切、粘贴、恢复外壳和转向保留其它格子的仓室分配；复制不修改规划。剪切只恢复源格壳子，粘贴只改目标格，并保留粘贴前的施工模式和范围。切换选中格、层、范围或施工模式不会重新分配。撤销/重做及草稿也保留原自动位置；如需按新配额重新安排，请明确重新生成仓室预设。

工具栏「快捷键」展开快捷键表，点击项目后按新的组合键；支持 Ctrl/Shift/Alt，冲突会拒绝，Esc 和无修饰的 1/2/3 保留。设置保存在客户端 `config/gtit-hologram-keys.properties`，可恢复默认。输入文字、弹窗与改绑捕获时不触发编辑快捷键。

方块选择有「主背包 / 材料来源」两页。来源页能直接选择已启用背包容器和 ME 中的样本，支持点击、拖拽、滚轮翻页和刷新来源。选择物品不会扣材料；清除单格指定后恢复模板目标。来源目录最多展示 96 种可放置样本；只有精确提取接口的背包不能枚举目录，但仍可供应已知目标所需材料。

手动目标允许合法 ItemBlock 或已注册的 GT 机器物品，不再以模板仓室白名单和自动仓室配额限制用户选位；线圈也可手动指定。自动选材仍按原结构规则执行。自由放置**不保证机器成型**，外壳最低数量、仓室种类和结构空气位仍取决于机器本身。

选择物品时，模板空位显示淡线框，可直接点击。没有模板位置时，使用「添加位置」，输入相对控制器的世界 X/Y/Z 偏移；位置须处于世界合法坐标和已加载区块。手动位置未指定目标时不会施工或拆除。重新扫描按坐标保留指定，不按旧列表下标套用。

校准先读取现场合法方块：已审查的材质信道在相关位置一致且唯一匹配时自动识别；线圈格按实际结构声明的线圈家族识别，不依赖仅含当前档位或为空的候选列表，并重新采集目标；这些位置不会被独立覆盖锁死。仓室布局和朝向保留，校准后可继续改变线圈等信道。诸神之锻炉环数读取原机数据；无法可靠反推的尺寸和自定义原始信道保留当前值，结果中明确提示。混合材质不伪造一个统一档位。

## 仓室候选、朝向与预设

选择位置后，右侧提供类型下拉选框与独立等级行。类型列表含「全部类型」并标出选中项；等级用「− / 等级值 / +」按该类型实际可用等级增减，点击中间值恢复全部等级，最高或最低不会循环。选择全部类型时只筛选，不自动改成另一种仓室；明确指定类型后可用等级联动目标。本格候选会标出当前选项；滚轮浏览，也可在「等级 / 信道设置」打开「可替换选项」完整目录。选项按结构声明展开方块、框架、已列出的阶层及仓室类型；手选不按“当前还缺哪类仓室”缩减，也不误用自动取材黑名单。自动预设与自动施工仍遵守原有过滤及配额。高炉底部外壳位可以查看声明允许的输入、输出、维护、能源等类型；顶部输出位置仍按自身声明展示。目录只给当前选中格发送，避免每个结构格都重复传输完整列表。GTSR 蒸汽枢纽的 A/C 格可以查看外壳与专用蒸汽部件；D/E/F 格可查看其已声明方块或框架。自定义校验无法完整解析时，标题显示「已知选项」，悬停说明识别边界；阶层组合仍要满足整台机器的一致性要求。虚拟预设只提供保存的调色板样本。

新放仓室优先面向外部空气，排除模板内部声明空气并遵循仓室与结构定义的合法方向；没有可证明的外部合法空气面时保留原生方向。点击主框「六面转向」或按 R，按北→东→南→西→上→下轮询，自动跳过方块或结构不允许的面。同一现有仓室在替换模式仅修改方向，不拆除、不扣材料；补建模式保留现有方向。新仓室预览材质按目标方向显示。封存设备默认保留自己的方向，显式指定方向只允许方向不同，库存和流体仍须严格一致。

「仓室预设」按选定电压级和冻结的结构声明配额分配目标位置，生成后施工范围同步为全结构，保留已有仓室和手选目标，并共享材料预留数量。关闭降级时严格保持等级；开启后按类型选择不超过目标等级的最高有料级，固定等级部件沿用定义。无仓室设置下，已安装且属于机器必需的合法仓室仍会保留；合法性沿用机器原有校验，手动固定位置优先。材料全缺时保留目标并显示缺口，不把同一枚物品重复算给多个位置。需要取消整机目标时，在预设面板点击「撤销预设」；保留已有仓室与手选目标，已施工结果不会撤回。生成目标后，在「材料与改动」查看需求、已启用来源可用量、主背包数量及控制器自身库存数量；控制器只读展示且受访问权限限制，不参与施工取料。创造模式明确提示普通材料无限，封存设备仍消耗真实物品。

预设只适用于能够读取声明配额的定义；未识别的定义和无位置、无等级候选会给出原因。外壳最低数量及其它额外成型检查仍由原机器判断。

## 材料来源设置

「材料来源」入口在工作台内设置主背包、背包容器、ME 三个来源及取料优先级；只启用的来源会参与检索、枚举和取料，设置保存在投影仪中。控制器自身库存数量仍是受权限保护的只读展示，不参与取料。Shift+右键打开工作台，不再打开旧版全局设置面板。

- 主背包：跳过手持投影仪的槽位。
- 背包容器：使用 StructureLib 已注册的容器提取器；未知或没有适配器的背包不承诺支持。
- ME：使用玩家携带的第一个无线终端，包括饰品槽。沿用终端原有绑定、范围、电量和提取权限，不需要另绑网络。

每格普通施工失败会退还实际扣除的材料。背包容器保留实际扣料后的状态，材料退到玩家背包；ME 优先退回网络，无法退回的余量进入玩家持久退款暂存。背包满时不会直接丢弃暂存；重新使用投影仪且有空间时继续返还，暂存随玩家持久数据保留。创造模式的普通材料无限，含库存或流体的封存设备仍消耗真实物品，避免复制设备内容。

## 拆除与设备回收

拆除始终跳过锚点控制器。完整捕获的非空气结构格，包括支持的 GT 仓室、框架和普通方块，均纳入拆除；空气声明且没有显式指定的格子不会拆除，无适配的非 GT 方块实体仍受保护。权限与破坏事件继续生效。

GT 设备的库存、流体及 covers 等保存在回收封存物品中，不迁移到替换后的新仓室。封存物品可恢复原设备；失败路径保留退款与回收物品。具体第三方设备的额外拆除副作用仍由其实现决定。

拆除不再受仓室预设目标影响。默认回收可选「主背包」或「ME 优先」；ME 关闭、终端不可用或网络未全部接收时回落主背包，余量进入玩家持久待领队列。背包满不会因为回收空间阻止安全施工或丢弃物品。回收发生在世界事务成功之后，ME 按实际接收余量计账和收费；施工失败则还原该格、退款实际扣料，不把旧设备掉落重复发放。暂存物在继续使用投影仪、有可用空间时继续投递。任意背包容器只有取料适配，不承诺作为自动回收插入目标。

## 草稿与自定义预设

草稿只属于当前投影仪，绑定维度、坐标和控制器类型，换控制器会覆盖旧草稿。保存信道、目标、朝向、预设和来源选项，不保存现场设备内容。小草稿写入投影仪 NBT；超过 256 项编辑或冻结目标时，草稿写入当前维度的服务器世界数据，投影仪 NBT 保留关联，避免物品同步包过大。大型草稿需要同一玩家、投影仪与原世界。清除草稿恢复默认规划，不撤回施工。

自定义蓝图保存在服务端 config/gtit/hologram-presets.json，最多 32 份，位置遵循世界合法坐标，配置文件仍保留 8 MiB 资源预算。保存时默认选择全部可写的方块 NBT 根条目，用户可逐项取消；取消的条目不会写入蓝图，设备身份保护字段始终保留，覆盖板独立选择。放置时临时取消某个 NBT 根条目或覆盖板只影响本次，不改已保存蓝图。虚拟蓝图仅用于补建，不提供替换或拆除模式。

蓝图编辑不会启用世界放置：修改目标、提示或保存都留在编辑状态。编辑后用 Alt+右键启动一次新的放置流程，每次均会重新选择蓝图并确认材料；普通列表选择不会直接启动投影。

蓝图选定和放置状态会提示下一步。Shift+Alt+右键用于开启或退出区域框选，不能用于施工。Alt+右键先启动一次放置；确认材料后进入世界预览，再用 Alt+右键锁定位置。Shift+右键打开工作台，点「确认执行」施工。锁定后的投影可用 Alt+右键取消。

### 蓝图提示、共享与兼容性

提示词可设在全局蓝图、选中方块或立体提示区；exclude 会把选中格从施工计划排除，恢复操作可重新纳入。蓝图页可导出和导入分享文件，文件由当前服务端单独管理。版本信息列出蓝图依赖的 Mod 版本，并以红、橙、青分别标记缺失、过时、超前；选中缺失方块可查看缺失点、方块 ID、来源 Mod 和蓝图版本。

### 蓝图资源条目与放置材料

保存时默认选择全部可写的方块 NBT 根条目；用户可逐项取消，取消的根条目不写入蓝图，设备身份保护字段始终保留。覆盖板独立选择。放置时可临时取消 NBT 根条目或覆盖板，只影响本次，不修改已保存蓝图。未取消的资源条目按精确数量验料，不自动降级：库存从主背包或适配的 AE 来源提供，流体由 AE 提供，储能以 EU 从无线电网拉取。

覆盖板按已安装 side 的实际 cover 物品计价，含 façade 物品 NBT；覆盖板独立关闭时不写回原蓝图选项。带 NBT 的流体若当前 AE2 rv3-beta-1080-GTNH 接口不能保留其 tag，会拒绝保留该条目，不会按无 tag 流体继续；可在保存或本次放置时取消对应根条目。未知 storage 格式同样拒绝，需取消条目或增加适配。

AE 下单 provider hook 默认禁用，不提供内置 crafting 或自动下单。当前 AE2 流体接口无法保留带 NBT 的流体时会拒绝该条目，可在保存或本次放置中取消；未知 storage 格式也会拒绝保留并提示适配边界。AE 数字 GridNode 所有者校准以当前世界数据中的玩家 ID 为准，不会改动 live 来源、NBT 或已保存蓝图；普通数值 p 不会被猜成所有者，取消 node 根条目仍保留 owner actor 与 g/k 信息。
虚拟投影移动只是客户端预览，锁定及施工由服务端检查锚点、权限、区块与材料。生存模式遇阻挡拒绝补建；创造模式可覆盖受支持的普通占位，仍保留控制器、设备及权限保护。需要替换已建结构时打开其真实控制器。未锁定且没有 GUI 时，手持投影仪按 R 绕世界 Y 轴水平旋转整份预设 90°（北→东→南→西），Ctrl+R 绕世界 X 轴垂直旋转 90°（北→上→南→下）；按住只触发一次，松开后可再次旋转。锚点不变，非对称结构的坐标、控制器完整 StructureLib 姿态和各格仓室朝向一起旋转，手动目标、添加位置和后续平移保留。机器不允许的新朝向或姿态会整体拒绝，不部分改动或丢弃目标；纯编辑、锁定、施工/暂停及采集中不允许整机旋转。旋转只改当前会话，不自动写服务器预设；打开工作台另存或更新预设才持久保存旋转结果，旧 schema=1 预设仍可读取。GUI 内 R 仍是选中仓室的单格六面转向，不执行整机旋转。旋转或重新定位后清除旧坐标编辑的撤销/重做记录，不支持撤销几何旋转。缺料降级只对同类仓室选不高于保存等级的有料部件，不改控制器或固定部件，不覆盖玩家在虚拟工作台手动改过的格子；关闭时保持保存目标。结构是否成型仍由原机器判断。

## 预览与执行边界

GUI 和世界预览使用材质图集、内部面裁剪和缓存；GT 控制器与仓室优先按实际或目标 front 查询纹理，缺失时回退库存材质方向映射，不运行动态方块实体模型。预设控制器完整 roll/flip 姿态已保存并用于施工；静态纹理仍按六向正面显示，不模拟额外 roll/flip 的贴图旋转。资源重载和结构快照变化会清除对应缓存，已匹配或完成格不重复显示待放 ghost。弹出材料与改动、选择等面板时隔离深度和渲染状态，阻止底层交互。

结构不再受 4096 格或 64 格半径限制。采集分 tick 继续，状态分片传输，收齐后统一更新；等待期间保留上一份完整投影。GUI 缓存表面拓扑与包围盒；世界投影按 16 格空间组缓存、分帧建立网格，仅绘制玩家视距和视锥内的部分。仍须加载区块，传输保留字节资源预算。

诸神之锻炉读取原机环数作为未显式设置时的默认值，并按渲染激活状态使用对应的物理结构。活动状态下没有差分时保留星体渲染与空气环，不调用会重新填回主环的创造构造。原机的升级与成型规则仍有效。

采集尚未完成时，施工等待采集再执行安全预检。捕获失败或不完整时不允许施工，提示无法安全确认遮挡；不会调用可能改写其它位置的原生构造。完整采集下只按所选范围执行安全逐格事务；没有差异时保留现状并提示没有待施工位置。活动态诸神之锻炉的星体渲染与空气环不会因回退构造被填回。

暂停、继续和取消只控制剩余操作，不撤销已经完成的格子。缺料或现场变化后，可调整来源、重新扫描并继续直接构建。

## 物品材质

投影仪物品为每帧 16×16 的金黄色猫头纯投影，无币边或底座。直接从实际物品猫猫币 `miao_coin.png` 的第一帧按原像素提取猫脸，保留折角眼、方鼻、偏侧猫嘴和横胡须，并去掉币边与星光。猫脸 RGB 保持原样，可见像素 alpha 255、背景 alpha 0，恢复常规物品渲染。六帧动画在不同区域以短条横移 ±1/2 像素形成明显信号噪声；3.05 秒循环中 78.69% 时间保持完整猫脸，各帧仅使用 0/255 透明度；制作提示、原图和转换脚本位于 `build/hologram-v1.8.79/`。

## 贸易配方与任务

在 NEI 查看物品配方或用途，选择「猫猫贸易」分类；也可点击猫猫贸易机催化剂查看全部交易。配方显示交易间隔（秒与 tick）、次数限制及 NBT 匹配规则。同格备选物品与矿词物品会轮切；输入、输出分别列格，组内多笔兑换和超过 12 格的内容通过「[<] / [>]」翻页。搜索会定位命中物品所在页。输出候选是可能产出，查看槽位提示区分随机候选和输入备选。

底部显示贸易配置已关联的 BQ 任务；点击打开任务页面。BQ 未安装或任务不存在时显示原因。未关联的交易显示无关联，投影仪购买没有绑定 ID38 解锁条件，避免先完成检索才能购买的循环。

默认贸易组仍有 92 条，投影仪使用独立内置交易组，价格仍为 1 枚闪烁猫猫币。v1.8.80 是默认组强制更新节点：从更早节点升级会按既有机制覆盖默认组，并通知玩家；独立投影仪组版本递进到 2，按稳定 UUID 更新，不重复创建。
