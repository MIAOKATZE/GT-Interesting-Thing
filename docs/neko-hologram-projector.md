# 猫猫全息投影仪

在猫猫贸易的 GTIT 分类中，用 **1 枚闪烁猫猫币**兑换。

手持投影仪右键多方块控制器，打开真实结构的预览和施工界面。右键空气可以编辑信道；投影仪配置随物品保存。中键拾取信道指示物沿用 StructureLib 的机制。

## 查看与配置

- 主信道相当于原版投影仪的数量参数。子信道可以单独覆盖它，例如 `coil`；未设置的子信道回退到主值。
- 可以添加、修改、删除任意合法的小写子信道。列表中的名称和说明来自已注册信道，第三方机器还可以使用自定义名称。
- 拖动预览旋转视角，滚轮缩放，点击方块查看候选部件。全息、现状和差分视图分别显示目标结构、已有方块和施工差异。
- 可以切层，也可以将施工范围设为全结构、当前层或选中位置。
- 朝向与镜像只列出机器允许的组合。实际改变控制器朝向只允许空地新建，不会自动搬移已摆放的机器。

## 建造、替换与拆除

**建造**补充空位；生存模式从玩家主背包取用材料，创造模式不消耗材料。材料页显示目前可以确定的所需量与可用量；不能确定的结构元素会明确保留为未知。

**原位升级**依据明确支持的结构元素处理替换。例如改变 `coil` 信道后，用目标线圈替换已有线圈；相同目标会保留，不会把某些更高等级的线圈单独留下而制造混级结构。详情中的候选选择用于空位新建取料；明确由信道指定的目标仍遵循信道，不会借候选选择替换受保护的设备。

**拆除**只处理已识别的普通结构部件。控制器、仓室、方块实体和未知方块保持保护；预览覆盖的区域并不意味着其中所有方块都能被拆除。

勾选**无仓室**后，不自动放置输入输出总线等方块实体。结构规则允许的位置使用外壳候选，固定接口仍需手动补齐；外壳完成不代表机器已成型。

施工按服务器 tick 分批推进。可以暂停、继续或取消；取消保留已完成的方块和材料消耗，不撤销整个结构。缺料或施工被拒绝时暂停，补充材料后可以继续。替换前会检查旧方块与材料，单格失败时恢复该格和本次材料变化。

**预演**只播放视觉时间线，不建造世界、不消耗材料。实际施工的落块动画跟随服务器成功回执。

关闭界面后，持有工具的施工仍会继续，可以直接观看世界投影；换手持槽位、离开控制器 64 格、跨维度、断线或目标变化会停止任务。

## 兼容与验证

高级预览与施工使用机器自身的 StructureLib 结构定义；不支持、不完整或未加载的结构不会伪造可执行计划。原版提示与原版构造回退保留机器自己的构造行为，回退不代表高级差分规则已经覆盖该机器。

回归入口：`gradlew.bat runHologramTest`。专用服冒烟需要本地已有 `run/server/mods` 的最小依赖集合：先运行 `python tools/hologram/prepare_smoke.py`，再运行 `gradlew.bat runServer -PhologramSmoke`。它使用 `build/hologram-smoke/server` 中的独立测试世界和本地端口，不使用共享测试实例；成功以 `[GTIT-HOLOGRAM-SMOKE] FINAL PASS` 为准。

客户端界面验证先运行 `python tools/hologram/prepare_client.py`，再运行 `gradlew.bat runClient -PhologramClientSmoke`。它读取专用服导出的真实结构，在独立目录请求 GUI 缩放 1、2、3，核验实际缩放、布局和 OpenGL，并保存截图；中文 Unicode 字体下实际缩放为 1、2、2。这一检查不包含联机点选、世界投影或施工交互。客户端额外依赖从 Gradle 缓存中读取，不改动共享实例。
