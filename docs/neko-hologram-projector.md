## 打开与查看

手持投影仪右键多方块控制器，采集目标并打开工作台；工具空中右键可打开界面，再右键控制器选择目标。有效任务期间重新右键同一 controller 会返回已有进度，不会覆盖或重启施工。

左侧可切换目标、现场与差分视图，拖动旋转视角、滚轮缩放，并切换全部图层或逐层查看；预览区下方的「世界投影」开关控制世界中的 ghost 显示。施工计划只有在服务端接受后才启动；此时界面关闭并打开世界投影。预览动画不代表施工完成。

## 等级与信道

「等级 / 信道设置」只列出当前结构已适配的值域，可滚轮查看完整列表。列表区分主值、显式指定、继承、机器默认、当前分支不使用及未知只读项；未知信道可以查看但不能编辑。悬停会解释选项语义和禁用原因。朝向只读，施工方向取 controller 当前朝向。

主原始信号范围为 1–64。未显式指定的子信道继承主信号或遵从机器默认规则；选「继承主信号」会清除该子信道的单独设置。不能在 UI 中任意新增未适配信道。

当前源码中已适配的能力包括：

- EBF 与 Coke Oven：14 档加热线圈；EBF 另有自动取用仓室开关。
- Extractor：8 档物品管道壳体、11 档玻璃。
- EIC：11 档玻璃及本地活塞材料名单。
- Mega Distillation Tower：5 档塔身层数。
- Coke Oven：2 档壳体、16 档构造分段参数。最高线圈分支下，长度信道不使用，分段数由主值决定。

能力只适用于对应结构，不表示其它机器也支持这些参数。

「原版提示」与「原版构造回退」调用机器自身的构造接口，不属于高级差分事务；它们不提供本工具的逐格保护和施工回执。原版构造回退后会重新采集，使用前后请自行核对现场。

## 选材与差分

「候选 / 材料清单」显示结构实际返回的候选与材料数量。「从背包指定目标」展示玩家主背包 36 格；点击物品后点目标槽，或把物品拖到左侧预览格。界面只发送槽位编号，服务端读取当前真实物品并重新验证。指定目标不会移动或消耗物品；确认并施工时才扣材料。选中的预览格由服务端同步。

普通方块目标必须是结构元素实际候选，或属于已识别、可枚举的安全结构族；仓室目标必须是结构真实提供的 hatch 候选，并经过服务端放置与结果核对。候选表示可尝试放置，不代表机器一定能成型。可以切换「只放外壳」与「允许仓室」；自动仓室选材仅适用于明确支持的结构能力，且不保证满足成型配额。

差分页可选建造、替换、拆除，并将施工范围设为全结构、当前层、选中格或同一已识别部件家族。控制器、已有 Tile Entity、带 cover 的设备、`MTE_BIT` 和未适配方块受保护，不会迁移其数据或配置。线圈替换通过等级信道指定，不使用背包目标覆盖。

frame 仅在无 Tile Entity 时受支持：GT `ofFrame(Materials)` 图标提示会补成对应具体方块与 meta；可枚举的 `ofBlocksTiered` 框架族也可进行精确族内选择，常见蒸汽框架为 Bronze/Steel。带 Tile Entity 的 frame 仍受保护。

## 确认与施工

确认前核对差分、材料缺口、回收物容量和保护原因。服务端接受计划后才开始逐格施工并关闭界面；成功放置、替换或拆除会通过 ACK 更新完成状态。界面重新打开时可查看进度。

建造与替换按世界高度由底向顶，拆除由顶向底。首层先预告 8 tick；每层按 20 tick 配额推进，层间等待 10 tick。服务器每 tick 有 2 ms 施工预算，负载较高时当前层会延长，不会越层抢跑。方块下落动画在预期提交前播放，只有服务端成功 ACK 才算完成；暂停时当前预告位置冻结。

可以暂停、继续或取消任务。暂停保留进度；取消保留已实际完成的方块和材料消耗，不回滚整项施工。单格放置失败会恢复该格与本次材料变化；缺料、受保护或未知接口会留下部分完成结果，调整目标或材料后重新扫描并确认新计划。投影仪不会替你执行机器成型检查；固定接口仍可能需要手工补齐。
