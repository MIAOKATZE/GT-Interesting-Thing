# 猫猫全息投影仪（v1.8.79）

在猫猫贸易的 GTIT 分类中，用 **1 枚闪烁猫猫币**兑换。本文按 v1.8.79 源码说明；本轮未启动游戏，实际交互与帧率由用户实测。

## 常用操作

| 要做什么 | 操作 |
| --- | --- |
| 选择机器 | 手持投影仪右键多方块控制器；空中右键重新打开工作台。 |
| 看结构 | 切换「目标 / 现场 / 差分」，拖动旋转、滚轮缩放，选择全部层或单层。预览显示真实方块材质；世界预览显示待放位置的静态半透明方块。 |
| 设置等级和子信道 | 打开「等级 / 信道设置」，选具名等级或填原始正整数；任意子信道可输入名称和值，再添加、更新或删除。 |
| 补齐结构 | 选「补建」和「全结构」，点击「直接构建」。即使没有变化，也允许执行机器原生构造。 |
| 按电压配置仓室 | 打开「仓室预设」选择电压级，决定是否允许缺料降级，生成目标后直接构建。已有仓室和手选目标保留。 |
| 外壳换仓室或其它方块 | 选「替换」，点击目标位置，打开方块选择，从主背包或材料来源选物品，点目标格按钮或拖到预览格，再点「应用替换」。 |
| 拆除结构 | 选「拆除」和「全结构」，点击「拆除结构」。始终保留作为锚点的控制器。 |
| 单格取消仓室或还原壳体 | 选中格，点击「恢复默认壳」或按 Delete；生成单格替换目标，再点「应用替换」。只是取消选中时使用右键、空白点击或「取消格选择」。 |
| 保存 / 重开草稿 | 正常控制器的规划自动存到投影仪 NBT；重新打开同维度、坐标和类型的控制器自动恢复。每个投影仪只保留一份。 |
| 恢复结构默认目标 | 打开「草稿 / 预设」，点击「恢复结构默认目标」并确认；不回滚世界、不删除配置中的自定义预设。 |
| 保存自定义预设 | 在真实控制器工作台编辑好结构，打开「草稿 / 预设」，输入名称并保存。模板包含控制器，保存在服务端配置。 |
| 凭空放置预设 | Alt 右键位置选择自定义预设，虚拟投影跟随准星；再次 Alt 右键锁定，再次 Alt 右键取消。Alt+Shift 右键直接施工，Shift 右键可打开工作台二次编辑。 |
| 全局设置 | Shift 右键空气打开取料来源、优先级、缺料降级、所选模板和默认回收去向；与工作台设置同步。 |

「材料与改动」用于提前查看，不是施工前置步骤。施工直接执行，不播放逐格放置或拆除动画；世界预览也不播放施工动画。原生构造合并在同一个按钮里，不再提供另一枚原版构建按钮。

## 选位置与自由替换

工作台采用 520×312 基准尺寸，左侧结构预览、右侧固定属性栏，二者不重叠；界面不随大屏放大，并按 Minecraft GUI 缩放后的可用区域收缩，宽高分别保留至少 10% / 15% 边距。普通点击用于检查位置，不会把施工范围悄悄改成单格。再次点击选中格、点击预览空白或右键可取消选中；主界面「取消格选择」同样可用。Esc 优先取消拖拽与弹窗，再取消格选择，最后退出工作台。Delete 和「恢复默认壳」明确把当前格设回结构默认壳体，并抑制预设重新填回；已造仓室要点击「应用替换」才实际回收和还原。无默认壳体的固定接口会说明原因，不猜造外壳。明确指定物品或添加位置后，自动转为单格；批量操作主动选择范围。

| 默认快捷键 | 作用 |
| --- | --- |
| Ctrl+X / C / V | 剪切、复制、粘贴目标和朝向；不复制设备库存、不立即施工。 |
| Delete | 恢复选中格的默认壳体目标。 |
| R | 按北→东→南→西→上→下轮询选中仓室的合法朝向。 |
| Ctrl+Z / Y | 撤回、重做最多 32 步目标规划；不回滚世界施工。 |
| 1 / 2 / 3 | 补建、替换、拆除模式。 |

连续快捷键最多排队 8 项，按服务端确认顺序执行；按世界坐标重新定位，关闭界面、切换会话或采集变化时取消待执行项。

局部剪切、粘贴、恢复外壳和转向保留其它格子的仓室分配；复制不修改规划。剪切只恢复源格壳子，粘贴只改目标格。切换选中格、层、范围或施工模式不会重新分配。撤销/重做及草稿也保留原自动位置；如需按新配额重新安排，请明确重新生成仓室预设。

工具栏「快捷键」展开快捷键表，点击项目后按新的组合键；支持 Ctrl/Shift/Alt，冲突会拒绝，Esc 和无修饰的 1/2/3 保留。设置保存在客户端 `config/gtit-hologram-keys.properties`，可恢复默认。输入文字、弹窗与改绑捕获时不触发编辑快捷键。

方块选择有「主背包 / 材料来源」两页。来源页能直接选择已启用背包容器和 ME 中的样本，支持点击、拖拽、滚轮翻页和刷新来源。选择物品不会扣材料；清除单格指定后恢复模板目标。来源目录最多展示 96 种可放置样本；只有精确提取接口的背包不能枚举目录，但仍可供应已知目标所需材料。

手动目标允许合法 ItemBlock 或已注册的 GT 机器物品，不再以模板仓室白名单和自动仓室配额限制用户选位；线圈也可手动指定。自动选材仍按原结构规则执行。自由放置**不保证机器成型**，外壳最低数量、仓室种类和结构空气位仍取决于机器本身。

选择物品时，模板空位显示淡线框，可直接点击。没有模板位置时，使用「添加位置」，输入相对控制器的世界 X/Y/Z 偏移；限已加载范围、64 格半径、最多 4096 个位置。手动位置未指定目标时不会施工或拆除。重新扫描按坐标保留指定，不按旧列表下标套用。

## 仓室候选、朝向与预设

选择位置后，右侧提供类型下拉选框与独立等级行。类型列表含「全部类型」并标出选中项；等级用「− / 等级值 / +」按该类型实际可用等级增减，点击中间值恢复全部等级，最高或最低不会循环。选择全部类型时只筛选，不自动改成另一种仓室；明确指定类型后可用等级联动目标。本格候选会标出当前选项；滚轮浏览，也可在「等级 / 信道设置」打开「可替换选项」完整目录。选项按结构声明展开方块、框架、已列出的阶层及仓室类型；手选不按“当前还缺哪类仓室”缩减，也不误用自动取材黑名单。自动预设与自动施工仍遵守原有过滤及配额。高炉底部外壳位可以查看声明允许的输入、输出、维护、能源等类型；顶部输出位置仍按自身声明展示。目录只给当前选中格发送，避免每个结构格都重复传输完整列表。GTSR 蒸汽枢纽的 A/C 格可以查看外壳与专用蒸汽部件；D/E/F 格可查看其已声明方块或框架。自定义校验无法完整解析时，标题显示「已知选项」，悬停说明识别边界；阶层组合仍要满足整台机器的一致性要求。虚拟预设只提供保存的调色板样本。

新放仓室优先面向外部空气，排除模板内部声明空气并遵循仓室与结构定义的合法方向；没有可证明的外部合法空气面时保留原生方向。点击主框「六面转向」或按 R，按北→东→南→西→上→下轮询，自动跳过方块或结构不允许的面。同一现有仓室仅修改方向，不拆除、不扣材料；新仓室预览材质也按目标方向显示。封存设备默认保留自己的方向，显式指定方向只允许方向不同，库存和流体仍须严格一致。

「仓室预设」按选定电压级和冻结的结构声明配额分配目标位置，生成后施工范围同步为全结构，保留已有仓室和手选目标，并共享材料预留数量。关闭降级时严格保持等级；开启后按类型选择不超过目标等级的最高有料级，固定等级部件沿用定义。材料全缺时保留目标并显示缺口，不把同一枚物品重复算给多个位置。需要取消整机目标时，在预设面板点击「撤销预设」；保留已有仓室与手选目标，已施工结果不会撤回。生成目标后，在「材料与改动」查看需求、已启用来源可用量、主背包数量及控制器自身库存数量；控制器只读展示且受访问权限限制，不参与施工取料。创造模式明确提示普通材料无限，封存设备仍消耗真实物品。

预设只适用于能够读取声明配额的定义；未识别的定义和无位置、无等级候选会给出原因。外壳最低数量及其它额外成型检查仍由原机器判断。

## 材料来源设置

「材料来源」和 Shift 右键空气的全局设置提供主背包、背包容器、ME 三个独立开关，默认都开启；仅启用来源才检索、枚举和取料。可选择优先主背包、优先容器或优先 ME，设置保存在投影仪中。控制器自身库存数量依然仅作受权限控制的只读展示，不作为取料来源。

- 主背包：跳过手持投影仪的槽位。
- 背包容器：使用 StructureLib 已注册的容器提取器；未知或没有适配器的背包不承诺支持。
- ME：使用玩家携带的第一个无线终端，包括饰品槽。沿用终端原有绑定、范围、电量和提取权限，不需要另绑网络。

每格普通施工失败会退还实际扣除的材料。背包容器保留实际扣料后的状态，材料退到玩家背包；ME 优先退回网络，无法退回的余量进入玩家持久退款暂存。背包满时不会直接丢弃暂存；重新使用投影仪且有空间时继续返还，暂存随玩家持久数据保留。创造模式的普通材料无限，含库存或流体的封存设备仍消耗真实物品，避免复制设备内容。

## 拆除与设备回收

拆除始终跳过锚点控制器。完整捕获的非空气结构格，包括支持的 GT 仓室、框架和普通方块，均纳入拆除；空气声明且没有显式指定的格子不会拆除，无适配的非 GT 方块实体仍受保护。权限与破坏事件继续生效。

GT 设备的库存、流体及 covers 等保存在回收封存物品中，不迁移到替换后的新仓室。封存物品可恢复原设备；失败路径保留退款与回收物品。具体第三方设备的额外拆除副作用仍由其实现决定。

拆除不再受仓室预设目标影响。默认回收可选「主背包」或「ME 优先」；ME 关闭、终端不可用或网络未全部接收时回落主背包，余量进入玩家持久待领队列。背包满不会因为回收空间阻止安全施工或丢弃物品。回收发生在世界事务成功之后，ME 按实际接收余量计账和收费；施工失败则还原该格、退款实际扣料，不把旧设备掉落重复发放。暂存物在继续使用投影仪、有可用空间时继续投递。任意背包容器只有取料适配，不承诺作为自动回收插入目标。

## 草稿与自定义预设

草稿只属于当前投影仪，绑定维度、坐标和控制器类型，换控制器会覆盖旧草稿。保存信道、目标、朝向、预设和来源选项，不保存现场设备内容。清除草稿恢复默认规划，不撤回施工。

自定义预设保存在服务端 `config/gtit/hologram-presets.json`，最多 32 份，每份最多 4096 个位置、64 格半径；只从服务端采集的合法结构保存，包含控制器的真实物品需求。方块和仓室记录注册物品、meta、相对位置和朝向，不克隆库存、流体、covers 或封存 NBT。虚拟预设只支持补建/明确替换，不提供拆除模式；原生构造和机器信道不可用于没有实体控制器的模板。

虚拟投影移动只是客户端预览，锁定及施工由服务端检查锚点、权限、区块与材料。默认不覆盖占用方块；需要替换时在工作台明确选择。模板使用保存时的结构朝向，可逐格旋转仓室。缺料降级只对同类仓室选不高于保存等级的有料部件，不改控制器或固定部件，不覆盖玩家在虚拟工作台手动改过的格子；关闭时保持保存目标。结构是否成型仍由原机器判断。

## 预览与执行边界

GUI 和世界预览使用材质图集、内部面裁剪和缓存；GT 控制器与仓室优先按实际或目标 front 查询纹理，缺失时回退库存材质方向映射，不运行动态方块实体模型。额外 roll/flip 尚未同步；六向正面已支持。资源重载和结构快照变化会清除对应缓存，已匹配或完成格不重复显示待放 ghost。弹出材料与改动、选择等面板时隔离深度和渲染状态，阻止底层交互。

捕获不完整时，补建按钮允许调用机器原生构造；替换和拆除要求完整捕获。原生构造按整台机器自己的规则执行，不应用手动覆盖或高级范围，单次预算有限，必要时再次点击。它沿用 StructureLib 的取料接口，部分构造失败时的扣料由原生元素决定，没有普通单格事务的通用退款保证。

暂停、继续和取消只控制剩余操作，不撤销已经完成的格子。缺料或现场变化后，可调整来源、重新扫描并继续直接构建。

## 物品材质

投影仪物品为每帧 16×16 的金黄色猫头纯投影，无币边或底座。直接从实际物品猫猫币 `miao_coin.png` 的第一帧按原像素提取猫脸，保留折角眼、方鼻、偏侧猫嘴和横胡须，并去掉币边与星光。猫脸 RGB 保持原样，可见像素 alpha 255、背景 alpha 0，恢复常规物品渲染。六帧动画在不同区域以短条横移 ±1/2 像素形成明显信号噪声；3.05 秒循环中 78.69% 时间保持完整猫脸，各帧仅使用 0/255 透明度；制作提示、原图和转换脚本位于 `build/hologram-v1.8.79/`。
